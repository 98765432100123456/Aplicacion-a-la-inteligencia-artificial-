Entrega del proyecto
====================

| Archivo | Contenido |
|---|---|
| [Entrega-Semana-12-ICA-Bienestar-Animal.pdf](Entrega-Semana-12-ICA-Bienestar-Animal.pdf) | Documento de la entrega de la semana 12: código del proyecto, repositorio Git, diseños de interfaz, diagramas UML y diseño de la base de datos |
| `fuente/entrega-semana-12.html` | Fuente del documento |

El PDF se genera imprimiendo la fuente con Chromium. Las fuentes tipográficas se cargan desde `frontend/node_modules`, por lo que antes debe ejecutarse `npm install` en la carpeta `frontend`.

La entrega de la semana 12 corresponde a la versión `v0.2.0`, cuando la base de datos era PostgreSQL y el modelo incluía las tablas diseñadas para los sprints siguientes. Para volver a generar ese PDF tal como se entregó se usa esa versión (`git checkout v0.2.0`). El diseño vigente de la base de datos, en MariaDB, está en [base-de-datos/DISENO-BASE-DE-DATOS.md](../base-de-datos/DISENO-BASE-DE-DATOS.md).
